OPNsense-Verbindung

Zugang zur API der Firewall und allgemeine Angaben

API-Zugang

Adresse der Weboberfläche aus Sicht dieses Containers, ggf. mit Port (z. B. https://10.0.0.1:4443).
Leer lassen, um die gespeicherten Werte zu behalten. Key und Secret werden verschlüsselt gespeichert.
Bei selbstsigniertem Zertifikat der OPNsense deaktivieren.

Allgemein

DNS-Name oder feste IP, unter der die OPNsense aus dem Internet erreichbar ist. Vorschlagswert für neue Tunnel.
Erscheint in Anleitungen, Profilnamen und in der Authenticator-App.
Wird in der Anleitung für Mitarbeiter angegeben.

Einrichtung auf der OPNsense

1. API-Benutzer anlegen

Unter System → Zugang → Benutzer einen Benutzer (z. B. vpnmanager) anlegen und ihm folgende Rechte geben:

  • VPN: OpenVPN: Instances
  • Status: OpenVPN
  • System: Trust: Authorities
  • System: Trust: Certificates
  • System: Access: Users
  • Firewall: Rules (optional, für automatische Regeln)

Dann beim Benutzer unter API-Keys einen Schlüssel erzeugen. Die heruntergeladene Datei enthält Key und Secret.

Hinweis: Wer Benutzer verwalten darf, hat faktisch Administratorrechte. Den API-Key deshalb nur in diesem Tool hinterlegen.

2. Authentifizierungsserver mit 2FA anlegen

Unter System → Zugang → Server einen Server hinzufügen:

  • Typ: Local + Timebased One Time Password
  • Name: z. B. VPN-TOTP
  • Rest auf Standard lassen (Code vor dem Passwort).

Diesen Server wählen Sie beim Anlegen eines Tunnels aus.
